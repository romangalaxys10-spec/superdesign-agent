It aggressively rejects the sea of generic AI clones (default Inter font, purple-to-pink gradient blobs, cookie-cutter 3-card layouts, hollow buzzwords) and replaces them with **Bespoke Typographic Systems, Swiss Bauhaus Grids, Industrial Hardware HUDs, and Tactile Depth**.

## 🚫 The 5 AI Slop Sins We Banned Forever

| Slop Anti-Pattern | Why It Is Slop | The Anti-Slop Solution |
|---|---|---|
| 🟣 **Purple Gradient Blur Blob** | The #1 lazy marker of every 2023 Dribbble AI generation. | High-contrast single-hue accents: Bold Vermillion (`#FF3B00`), Phosphor Amber (`#FFB000`), Acid Lime (`#CCFF00`). |
| 🔤 **Default Inter / Open Sans** | Statistical average typography with zero soul or editorial contrast. | Bespoke pairings: `Syne` + `Space Grotesk`, `Playfair Display` + `Instrument Sans`, `Chivo Mono`. |
| 🃏 **Symmetric 3-Card Monotony** | Predictable identical rounded rectangles with no hierarchy. | Asymmetric Swiss grids, oversized typography, hairline border rules, and discrete bounding boxes. |
| 🗣️ **Hollow Marketing Buzzwords** | Clichés like *"supercharge"*, *"empower"*, *"seamlessly"*. | Direct, high-information technical statements and quantifiable benchmarks. |
| 🌫️ **Sterile Flat Dark Mode** | Bland grey background with zero depth or physical feel. | Integrated SVG noise grain overlays, industrial dot-matrix grids, and tactile hardware bezels. |

## 🚀 Quick Start

### 1. Installation

```bash
git clone https://github.com/romangalaxys10-spec/superdesign-agent.git
cd superdesign-agent
pip install -e .
```

### 2. Audit Any Website for AI Slop

```bash
superdesign audit --file ./my_site.html
```

### 3. Generate a Swiss International Site

```bash
superdesign site \
  --title "KryptonFlow" \
  --tagline "SWISS ARCHITECTURE" \
  --prompt "Deterministic Solana slot streaming engine with sub-millisecond telemetry" \
  --theme swiss_international
```

### 4. Generate a 16:9 Keynote Deck

```bash
superdesign slide \
  --title "The Anti-Slop Manifesto" \
  --presenter "Chief AI Architect" \
  --theme swiss_international
```

### 5. Generate an Industrial Telemetry HUD

```bash
superdesign product \
  --name "SentinelOps" \
  --theme industrial_hud
```

### 6. Launch Live Preview Canvas

```bash
superdesign serve --port 8080
```
